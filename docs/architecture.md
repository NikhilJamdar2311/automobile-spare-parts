**Version:** 1.0 (MVP)

# Objective

Build a web application for managing an automobile spare parts shop.

The application should manage:

- Customers
- Mechanics
- Products
- Categories
- Inventory
- Purchases
- Invoices
- Payments
- Outstanding Balance
- Reports
